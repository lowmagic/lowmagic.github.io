ideamachine

Python 3.13 Postgres 16 + pgvector Claude SDK sentence-transformers

Most recorded speech is small talk. Idea Machine groups Hearsay’s utterance stream into content-addressed episodes, extracts ideas, tasks, and decisions with exact line citations, and relates each idea to prior ones across themes.

  • Deterministic rebuilds: Every derived row records code, model, and prompt version; human verdicts anchor to transcript segments so they survive re-segmentation.
  • Pseudonymized & budgeted egress: Speakers map locally to me, S1, S2 per request, gated by a pre-flight monthly spend cap.
  • Measured, then simplified: Cheap triage routers were benchmarked against hand labels, then retired once replay data proved routing wasn’t earning its keep.

02 / Support-Case Triage

Evidence-checked investigation over diagnostic archives

compa

Go Sandboxed Tools Secret Redaction Vertex AI / OpenRouter

A terminal companion in Go for investigating support cases and unpacked diagnostic bundles. Out of the box it makes zero network calls; when connected to a model, every file read runs through deterministic sandboxed tools and secrets are redacted before leaving the host.

  • compa-engine: Go library owning sandboxed collection, cache-friendly conversation ordering, redaction, digest-pinned bundles, and evidence checks.
  • compa-experts: Embedded domain experts, file-inspection catalogs, and routing rules.
  • Human-owned conclusions: Compa states what the data shows, what remains open, and what artifact settles it—it never diagnoses or posts to a case.
